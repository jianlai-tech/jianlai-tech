# 接单留资

## 谁来

中小企业老板或负责人，从自媒体点进本站。

## 表单

| 字段 | 必须 | 说明 |
|------|------|------|
| 公司 | 是 | 自由文本 |
| 联系人 | 是 | 称呼即可 |
| 手机 | 是 | 中国大陆 11 位 |
| 微信 | 否 | |
| 场景 | 否 | 家教教培 / 分销批发 / 制造贸易 / 其他 |
| 备注 | 否 | 现在卡在哪 |
| 来源 | 系统写 | 默认 `官网` |

## 回访

1. 写入 `leads`。
2. 人打电话或加微信。
3. 判断能不能驻场。不能做的要回绝，禁止先收钱再看现场。

## 对外口径

- 必须写行业，禁止写客户真名。
- 禁止编数字。
- 家教现场可以讲工序：试课、成交、消课、课酬、员工 / 老师 / 家长端。
- 禁止把家教现场讲成招生广告。
