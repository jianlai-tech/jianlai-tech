# 接单留资

## 谁来

中小企业老板或负责人，从自媒体或案例集点进本站。

## 表单

留资分两种，页面顶部两张签切换（`/start` 是公司项目，`/start?kind=referral` 是转介绍）：

| 类型 | `kind` | 谁来填 | `source` |
|------|--------|--------|----------|
| 公司有项目 | `project` | 自己公司要做 | `官网` |
| 帮朋友引荐 | `referral` | 替朋友公司牵线 | `转介绍` |

两种都只填三样：

| 字段 | 必须 | 说明 |
|------|------|------|
| 简要介绍（`note`） | 是 | 项目：哪里卡住了；转介绍：是谁家、什么情况 |
| 称呼（`contact_name`） | 是 | 转介绍时是引荐人的称呼 |
| 手机（`phone`） | 是 | 中国大陆 11 位；转介绍时是引荐人的手机 |

`company_name` / `wechat` / `scene` 库里还留着，表单不再收，回访时补。表结构变更见 `schemas/003_leads_kind.sql`。

## 回访

1. 写入 `leads`。
2. 主理人或指定的人打电话或加微信。
3. 转介绍：先打给引荐人了解情况，由引荐人牵线，**禁止跳过引荐人直接联系对方公司**。
4. 判断能不能驻场。不能做的要回绝，禁止先收钱再看现场。
5. 能做的按现场派驻场。

## 对外口径

- 必须写行业，禁止写客户真名。
- 禁止编数字。
- 家教现场可以讲工序：试课、成交、消课、课酬、员工 / 老师 / 家长端。
- 禁止把家教现场讲成招生广告。
