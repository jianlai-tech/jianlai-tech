# 英雄帖

官网 `/join` 是一张独立的帖子页，不套官网顶栏页脚，也不在顶栏挂 tab。入口只有官网页脚一条链接，主要靠直接发链接。

页面：暗红底上一封大红帖，点火漆「启帖」。桌面封面绕左缘翻开成对开，左页金字竖排帖文 + 「剑修四要」，右页米色投名状；手机上封面掀走，帖文和投名状上下排。三问答完，点「画押」按指印提交。二期 `source` 记为 `英雄帖·二期`。

顶栏：剑来科技 + 「剑修二期招募」。帖内正文后压「剑心通明」，卷尾落款「剑来 · 望城 · 风起大泽篇」。

## 剑修二期（2026-10 起）

面向**中南大学在校生**，做意向收集。

| 年级 | 能走的路 |
|------|----------|
| 大一、大二 | 只能「观摩学习」：跟着看真实项目怎么做 |
| 大三、大四、研究生、博士 | 「观摩学习」或「驻场接活」；接活要保证时间精力投入 |

前端选大一大二时「驻场接活」置灰；后端也会把大一大二压回 `watch`，前端绕不过。

剑修四要（帖子页展示）：韧（扛压）、勤（时间精力投入足）、敏（学习和沟通）、技（有计算机基础更好，没有就加倍下苦功）；加分项：艺（唱歌、跳舞、设计、体育等一技之长）。

## 表单

写入 `recruits` 表（DDL `schemas/006_recruits.sql` + `007_recruits_intent.sql`；API 启动时跑 `apps/jianlai-api/sql/` 同名文件）。

| 字段 | 必须 | 说明 |
|------|------|------|
| 姓名 `name` | 是 | |
| 学院 `school` | 否 | 二期写学院；一期是「学校和年级」 |
| 专业 `major` | 是 | |
| 年级 `grade` | 是 | 大一 / 大二 / 大三 / 大四 / 研一 / 研二 / 研三 / 博士 |
| 意向 `track` | 是 | `watch` 观摩学习 / `work` 驻场接活 |
| 每周时间 `weekly_hours` | 是 | 10 小时以内 / 10–20 / 20–30 / 30 小时以上 |
| 计算机基础 `cs_base` | 是 | 计算机相关专业 / 自学过编程 / 用 AI 做成过东西 / 暂时没有 |
| 一技之长 `talents` | 否 | 多选：唱歌、跳舞、设计、体育、摄影剪辑、写作、主持表达、乐器、组织活动 |
| 说说你自己 `strengths` | 否 | 四问，最多 800 字；页面列出项目、AI、特长程度、来意四条引导多写 |
| 手机 `phone` | 是 | 大陆 11 位 |
| 微信 `wechat` | 否 | |

预设项在前端 `JoinPage.tsx` 与后端 `routes/recruits.py` 白名单各一份，改选项两边一起改。一期字段 `age`、`ai_story` 保留可空，旧帖照常显示。

同一手机号 24 小时内再递，更新原帖，不另起一条。

## 后台跟进

内务后台「英雄帖」（`/dashboard/recruits`），只有管理员能看，接口 `/api/admin/recruits`（可按 `status`、`track` 筛，返回 `tracks` 计数）。侧栏角标是新帖数。

状态：新帖 → 已约聊 → 试手中 → 已入门 / 不合适。每张帖可写道长批注。

入门后照常走「账号 → 新开同门」开号，门派、境界由道长定。

## 对外口径

- 帖子页不写门派、境界、四维。
- 不承诺薪资、名额、转正。
- 不写成培训班招生，剑修是跟着真实项目边做边学。
