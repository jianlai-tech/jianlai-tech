# 英雄帖

剑来扩招，从大学生开始铸剑。官网 `/join` 是帖子页，顶栏「英雄帖」、页脚、剑修名册页都能进。

## 谁来

在读大学生，专业不限，看的是对 AI 是不是真上心：自己折腾过什么、卡在哪、怎么过去的。

## 表单

写入 `recruits` 表（DDL `schemas/006_recruits.sql`）。

| 字段 | 必须 | 说明 |
|------|------|------|
| 姓名 `name` | 是 | |
| 年纪 `age` | 是 | 14–60 |
| 专业 `major` | 是 | |
| 学校和年级 `school` | 否 | |
| 和 AI 打过的交道 `ai_story` | 是 | 最多 1500 字 |
| 自己的特长 `strengths` | 是 | 最多 800 字 |
| 手机 `phone` | 是 | 大陆 11 位，只用来约聊 |
| 微信 `wechat` | 否 | |

同一手机号 24 小时内再递，更新原帖，不另起一条。

## 后台跟进

内务后台「英雄帖」（`/dashboard/recruits`），只有管理员能看，接口 `/api/admin/recruits`。侧栏角标是新帖数。

状态：新帖 → 已约聊 → 试手中 → 已入门 / 不合适。每张帖可写道长批注。

入门后照常走「账号 → 新开同门」开号，门派、境界由道长定。

## 对外口径

- 帖子页不写门派、境界、四维。
- 不承诺薪资、名额、转正。
- 不写成培训班招生，剑修是跟着真实项目边做边学。
