# K12 一对一家教

驻场把一家教培公司的日常经营做成系统。对外只写行业。

## 进场时卡在哪

试课、成交、上课、消课、课酬、家长沟通散在表格和聊天里。谁该跟下一节、剩多少课时、老师怎么结，对不上。

## 做成了什么

一条能跑的经营链路，不是一套招生页。

| 工序 | 现场在做什么 |
|------|----------------|
| 试课 | 约课、到课、结果回到转化 |
| 成交 | 录单、课时入账 |
| 消课 | 正课提交、审核、余量扣减 |
| 课酬 | 按过审的课结给老师 |
| 四端 | 员工、老师、家长各看自己该看的 |

## 谁在用

教务、转化、老师、家长。系统在客户现场跑，不在本站演示。

## 对外怎么讲

「派人进一家 K12 一对一家教公司，把试课到课酬做成能跑的系统。」

禁止讲成「帮你招学员」「智能排课 SaaS」。
