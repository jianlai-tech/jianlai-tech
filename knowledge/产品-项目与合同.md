# 项目与合同

内务后台原来的「销售」改为「项目管理」（2026-10-14 主理人定）。页签：项目 / 报价 / 合同 / 剑修在跟 / 留资线索。只管理员可见；对外（官网、案例）仍只写行业，不写客户名。

## 一个项目的全流程（2026-10-14 主理人定）

```text
需求 → 报价 → 签约 → 前期 → 中期 → 后期 → 维护 →（已完结）
                                          └ 维护期新功能：开「模块」（子项目），同一家公司，单独走一遍
```

| 阶段 | 干什么 | 系统里怎么推 |
|---|---|---|
| 需求 | 客户发来的需求文档、纪要、原型上传到项目（PDF / Word / Excel / PPT / 图片 / 文本，20MB 内，存 `project_docs`） | 新建项目默认在这 |
| 报价 | 项目制按模块列人天和价格，导出《报价估算书》Word 发客户；状态：拟定中 → 已发客户 → 客户已认 / 没谈成。派遣制可跳过 | 出第一份报价自动推到「报价」 |
| 签约 | 拟合同（项目制从报价带总价、工期、付款节点、功能清单）→ 导出 Word → 现场签 → 上传留档 | 拟合同推到「签约」，客户报价自动标「已认」；上传留档推到「前期」 |
| 前期 / 中期 / 后期 | 每期有开始/结束日、目标、这期收款和到账日；状态 未开始 / 进行中 / 完成 | 某期标「进行中」或「完成」，项目阶段跟着推 |
| 维护 | 质保与月度运维，只修 bug 和小需求 | 维护期同上 |
| 新模块 | 小程序、App、新业务模块等大功能，在主项目里「新增模块」，挂 `parent_id`，客户全称、行业、企业账号沿用主项目，从「需求」重新走 | 列表里缩进显示在主项目下 |

阶段只往前推、不往回拉（`_advance`），要回退在「改资料」里手动选。合作企业账号看到的进度条只从「签约」开始。

旧阶段（2026-10-14 迁移 `010_pipeline.sql`）：先看 → 需求、先斩一处 → 中期、上线护航 → 后期、教会交接 → 维护。驻场 SOP 里的「先看、先斩一处、上线人不走、教会再走」仍是对外讲法，不再当系统阶段。

## 两种签约方式

| 方式 | 怎么收钱 | 合同 |
|---|---|---|
| 派遣制 | 按人月：每位剑修每月服务费 + 道长全程跟进的顾问费（每月） | 《驻场技术服务合同（按人月）》 |
| 项目制 | 固定总价，按里程碑付款，按功能清单验收 | 《技术开发服务合同（项目制）》，附件一功能清单从报价模块生成 |

**合同里不写「劳务派遣」。** 剑来没有劳务派遣经营许可，派遣制条款写明驻场人员与甲方不构成劳动 / 劳务 / 劳务派遣关系。

### 派遣制口径

- 麦芽AI 首单（一个月）：云故、木木、小鱼、囧 4 位，每人每月 3000，道长顾问费每月 7000，每月合计 19000。
- 付款（麦芽首单起）：首月 50% 预付（签约后 3 个工作日内、且早于进场日）+ 50% 月末结清；续期月份在当月开始前一次付清。
- 续期：期满前 7 日双方都没书面说不续，按原条款自动续一个月。
- 第三方资源费（服务器、大模型 API 等）：甲方承担，不进服务费。优先甲方自己开户直付；我们代付的走预付备用金（模板默认 3000，与首期款同付），按实际扣费不加价，每月给账单，余额低于 1/3 补足，超额先确认，终止多退少补。
- 服务期：一个月 = 开始日到下月同日的前一天（10-20 起 → 11-19 止）。

### 项目制口径（一往职前首单起）

- 按人天估算 → 模块列价给固定总价；对外说比常规外包低 40%–50%。估算书自动生成「与常规外包对比」：常规按 1,000–1,200 元/人天、人天 ×1.3–1.4、工期 ×1.4–1.7 估区间。
- 付款默认 40% 预付 / 30% 中期演示 / 25% 验收 / 5% 质保（上线满 1 个月）；比例加起来必须 100%。
- 提交验收 7 个工作日不提书面问题视为通过；质保 1 个月。
- 运维按月 1,500–3,000 元两档，只含修 bug 和小需求；小程序、App 等大功能另签项目（系统里开新模块）。
- 开发期 AI 编程 / 模型费用含在总价里按工期包干（超出我们扛，甲方变更导致延期另计）；项目运行资源（服务器、短信、上线后产品调用的大模型等）甲方名下直付。
- 每周驻场沟通次数写进报价和合同（一往职前每周 2 次，每次约 2 小时，不累计）。
- 合同结束日按报价工期算（开始日 + 周数 × 7 − 1）。
- 一往职前一期：6 万（开发 5.5 万 + AI 包干 5,000，94 人天、7 周，含职前规划助手），报价 `BJ-202610-01`，切入价，不再往下让；对方压价就砍模块。

## 通用条款

- 乙方主体、对公账户取 `knowledge/公司.md`（模板 `contract_doc.py` 的 `PARTY_B`）：招行长沙学士支行基本户，只收对公转账；含税价、收款后开票。
- 知识产权：甲方付清对应费用后成果归甲方；剑来原有通用框架保留权利、甲方永久免费使用。
- 合同编号 `JL-年月-序号`（按开始月份）；报价编号 `BJ-年月-序号`（按出报价月份）。
- 已签合同、客户已认的报价都不能改，要改就作废 / 另出一份。作废已签合同会把这份合同挂上的剑修撤下（别的有效合同还挂着的不撤）。
- 上传留档后：有后台账号的剑修自动挂进项目成员；「剑修在跟」页签：拟定中 = 拟派，已签未到开始日 = 待进场，已签进行中 = 在跟，同时跟两个以上标红。

## 下载

- 报价估算书：项目管理 → 报价 → 选报价 →「下载估算书 Word」（或项目流程第 2 步「下载估算书」）。接口 `GET /api/admin/quotes/{id}/docx`。
- 合同：项目管理 → 合同 → 选合同 →「导出 Word」。接口 `GET /api/admin/contracts/{id}/docx`。
- 需求文档：项目流程第 1 步点文件名。接口 `GET /api/admin/docs/{id}/file`。
