## 流程

1. 项目管理 → 合同 → 拟新合同：选项目、填甲方全称、开始日、月数、单价、顾问费，勾剑修和岗位。旁边会提示哪位剑修已经在跟别的项目。
2. 导出 Word（`python-docx` 后端生成，乙方主体信息取 `knowledge/公司.md`）。开户行、账号、税率留空线，现场手填。
3. 现场签完，拍照或扫 PDF，在合同详情里「上传留档」（PDF / 图片 / Word，15MB 内，存库 `contracts.file_data`）。
4. 上传即转「已签」，联动：
   - 项目写上合作方式、起止日，阶段从「先看」推到「先斩一处」；
   - 有后台账号的剑修自动挂进项目成员（他们「我的档案」里能看到）；
   - 「剑修在跟」页签：拟定中 = 拟派，已签未到开始日 = 待进场，已签进行中 = 在跟，同时跟两个以上标红。
5. 已签合同不能改，要改就作废后新拟。作废已签合同会把这份合同挂上的剑修撤下（别的有效合同还挂着的不撤）。

服务期：一个月 = 开始日到下月同日的前一天（10-20 起 → 11-19 止）。合同编号 `JL-年月-序号`，按开始月份排。
