## 中高风险

1. 密钥、证件号、银行卡、未脱敏手机进 git 或打进前端包。
2. 越权：敏感接口只认 query、前端藏按钮当权限。
3. SQL 拼接、破坏性 DDL、无 WHERE 的 UPDATE/DELETE。
4. 主路径回退：登录、CORS、健康检查、内务 API 根地址。
5. 跨面漏改：DDL 与代码、CORS 与 Pages 域、`VITE_API_BASE_URL`、官网/内务两处文案。

命名和视觉偏好不阻断。

## 剑来专用

- 对外名只有「剑来 / 剑来科技」，禁止「见来」。

- 写入时间用 `now_cn()`，禁止 `datetime.now()`。
- SQL 占位符 `$1/$2`。
- 人事、账号本地 csv 不提交。生产 seed 不是 ship。
